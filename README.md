# 🧠 MYWIKI — Умная база знаний на Markdown с полнотекстовым поиском

**Легковесная, быстрая и масштабируемая вики-система для команд и одиночных разработчиков.**

---

## О проекте

Проект **MYWIKI** разработан @Bybyscan как легковесная вики-система для технической документации и баз знаний.
В основе рендеринга Markdown лежат библиотеки **Parsedown** и **ParsedownExtra**, созданные Emanuil Rusev (лицензия MIT).
ParsedownExtra добавляет поддержку таблиц, футнотов и других расширений Markdown Extra, что делает контент более структурированным и удобным для восприятия.

Подробнее о библиотеках:

- [Parsedown на GitHub](https://github.com/erusev/parsedown)
- [ParsedownExtra на GitHub](https://github.com/erusev/parsedown-extra)
- [ParsedownExtra на Packagist](https://packagist.org/packages/erusev/parsedown-extra)

Исходный код MYWIKI доступен в репозитории:
[github.com/testbybyscan-del/MYWIKI](https://github.com/testbybyscan-del/MYWIKI)

---

## Зачем ещё одна вики?

Вы устали от громоздких CMS, сложных конфигураций и дорогих хостингов?
Хотите хранить техническую документацию, заметки, руководства и шпаргалки в одном месте, с удобным поиском и поддержкой Markdown?

**MYWIKI** создана именно для этого. Она:

- **Проста в установке** — запускается одной командой через Docker.
- **Гибкая** — все страницы хранятся как `.md`-файлы в Git, так что вы можете редактировать их в любом редакторе и отслеживать изменения.
- **Мощная** — полнотекстовый поиск на русском языке, поддержка таблиц, футнотов и других расширений Markdown.
- **Безопасная** — встроенный скрипт санитизации маскирует IP-адреса и порты, прежде чем попасть в публичный репозиторий.
- **Автоматизированная** — вебхук обновляет сайт и базу данных при каждом push в репозиторий.

Идеальный выбор для технической документации, внутренних вики, личных заметок и даже для публичных баз знаний.

## 🛠 Технологический стек

- **Backend:** PHP 8.x (PDO_PGSQL)
- **База данных:** PostgreSQL 15 (полнотекстовый поиск через `tsvector`)
- **Контейнеризация:** Docker + Docker Compose
- **Markdown-парсер:** ParsedownExtra (поддержка таблиц и расширенного синтаксиса)
- **Фронтенд:** Vanilla HTML/CSS/JS — никаких тяжёлых фреймворков
- **Автоматизация:** Webhook для интеграции с GitHub

## ⚡ Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone git@github.com:testbybyscan-del/MYWIKI.git
cd MYWIKI
```

### 2. Настройте окружение

```bash
cp .env.example .env
# Отредактируйте .env — укажите свои пароли и порт
```

### 3. Запустите контейнеры

```bash
docker-compose up -d
```

Готово! Откройте `http://localhost:53002` (или ваш порт) — вы увидите главную страницу.

### 4. Импортируйте страницы

Положите свои `.md`-файлы в папку `pages/` и выполните:

```bash
docker exec -it wiki-pesah php import.php
```

Файлы должны называться по шаблону: `[номер]._[язык]._[тема].md`.

## 📝 Поддержка таблиц в Markdown

Теперь вы можете использовать таблицы в своих страницах:

```markdown
| Заголовок 1 | Заголовок 2 |
|-------------|-------------|
| Ячейка 1    | Ячейка 2    |
| Ячейка 3    | Ячейка 4    |
```

**Правила:** перед таблицей обязательна пустая строка, разделитель — `---`. Поддерживается выравнивание через двоеточия (`:---`, `:---:`, `---:`).

## 🔒 Санитизация данных (важно для публичных репозиториев)

Скрипт `sanitizer.php` автоматически заменяет публичные IP-адреса и порты выше 12000 на плейсхолдеры. Запустите его перед коммитом:

```bash
docker exec -it wiki-pesah php sanitizer.php /var/www/html/pages
```

Это защитит ваши реальные IP и порты от случайной утечки.

---

## 🔄 Автоматическое обновление через вебхук

Настройте вебхук в GitHub (Payload URL: `https://ваш_домен/webhook.php`, Secret: задайте в `webhook.php`). При каждом push в `main` сайт и база данных обновляются автоматически.

## 📂 Структура проекта

```
MYWIKI/
├── docker-compose.yml      # (именованные тома, здоровьечек, сеть)
├── Dockerfile              # PHP 8.x + Apache
├── .env                    # Переменные окружения
├── pages/                  # Ваши .md-файлы (игнорируются Git, только .gitkeep)
├── import.php              # Консольный импорт
├── index.php               # Главная страница с поиском
├── load_file.php           # Загрузка и рендеринг страниц
├── sanitizer.php           # Санитизация IP и портов
├── webhook.php             # Обработчик GitHub webhook
├── Parsedown.php           # Базовый парсер
├── ParsedownExtra.php      # Расширение для таблиц
├── script.js               # Клиентская логика
├── styles.css              # Стили (адаптив + таблицы)
└── init-db.sql             # Инициализация БД
```

## 🔧 Переменные окружения (`.env`)

| Переменная | Назначение | Значение по умолчанию |
|------------|------------|-----------------------|
| `POSTGRES_DB` | Имя базы данных | `wiki` |
| `POSTGRES_USER` | Пользователь БД | `wiki_user` |
| `POSTGRES_PASSWORD` | Пароль | `secure_password_change_me` |
| `WIKI_PORT` | Порт веб-интерфейса | `53002` |
| `DB_HOST` | Хост БД (имя сервиса) | `db` |
| `DB_NAME` | Имя БД (для PHP) | `wiki` |
| `DB_USER` | Пользователь (для PHP) | `wiki_user` |
| `DB_PASSWORD` | Пароль (для PHP) | `secure_password_change_me` |

**Рекомендуется** менять все пароли перед запуском в продакшене.

## 🧪 Тестирование и логирование

Все действия логируются в `/tmp/wiki_debug.log` внутри контейнера. Просмотр:

```bash
docker exec wiki-pesah cat /tmp/wiki_debug.log
```

Логи помогают быстро диагностировать проблемы с импортом, подключением к БД и рендерингом.
